# IT'S MAIPAINT TECH

Static PWA website. All files are in the root (no folders).

## Host on GitHub Pages
1. Upload ALL these files to a GitHub repo (root, not inside a folder).
2. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
3. Open https://YOUR-USERNAME.github.io/REPO-NAME/

## Update the site
After changing any file, bump VERSION in sw.js (e.g. maipaint-v2) so phones fetch the new files.
